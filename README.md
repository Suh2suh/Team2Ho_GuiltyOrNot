## 프로젝트 소개
AI 재판관들의 증언을 듣고, 플레이어가 직접 판결과 근거를 선택하는 법정 시뮬레이션 게임입니다
<br>
[현재 버전]
- AI API 연동을 고려한 게임 흐름과 UI 구조를 중심으로 제작
- CaseData 1개로만 진행 (추후 확장 가능)
