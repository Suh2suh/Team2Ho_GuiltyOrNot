# Guilty? ...or Not?

AI 재판관들의 증언을 듣고, 당신만의 판결을 내려라!

## 프로젝트 소개
AI 재판관들의 다양한 관점을 바탕으로 사건을 심리하고,
플레이어가 직접 유죄/무죄 판결과 판결문을 작성하는 캐주얼 법정 시뮬레이션 게임

## 개발 환경
- Unity 6, Unity C#, Windows Platform
- 3D(Enviroment) + 2D (Entities)


## 외부 라이브러리/에셋 (All-FREE)
- DoTween
- UniTask
- Newtonsoft Json
- 3D Model Assets


## 담당 역할
- Unity 클라이언트 개발
- 게임 UI 구현
- 재판 진행 플로우 구현
- 판결 입력 및 결과 UI 구현
- AI 응답 연동 가능 구조 구현 (AI API 미연결 상태)
